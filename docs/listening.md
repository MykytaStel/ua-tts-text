# Що послухати

У `samples/ab/` лежать пари файлів на одні й ті самі речення:

- `N-prepared.wav` — текст готував `ua-tts-text` (числа, дати, наголоси, лексикон);
- `N-fallback.wav` — старий шлях: підготовка всередині Python-скрипта tts-uk.

Речення:

1. У 1675 році на 5 км шляху — 22% вологи. Замок стоїть на горі.
2. Київ, Харків і Кам'янець-Подільський — три різні історії.
3. Бюджет — 250 тис. грн, а зібрали 2,8 млн за 4 роки.
4. Дорога веде до села, де народився Іван Франко.
5. ЗСУ, ООН і НАТО згадують у новинах, і т.д.

## На що звертати увагу

| Що | Де шукати |
|---|---|
| «замо́к» замість «за́мок» | 1 |
| «горі́» замість «го́рі» | 1 |
| читання «5 км», «22%» | 1 |
| «Ки́їв» і «Ха́рків» | 2 |
| два наголоси у «Кам'янець-Подільський» | 2 |
| «250 тис. грн» і «2,8 млн» | 3 |
| «за 4 роки» (не «четверті роки») | 3 |
| «Франко́» | 4 |
| абревіатури по літерах | 5 |

## Як згенерувати заново

```bash
# у worktree фабрики
UA_TTS_DICT=~/.local/share/ua-tts-text/dict.bin node scripts/ab.ts
```
