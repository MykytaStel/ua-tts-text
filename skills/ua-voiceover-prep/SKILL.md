# Підготовка українського тексту до озвучки

## Коли це потрібно

- Сценарій містить цифри, роки, дати, відсотки, одиниці, «ст.», «тис.», «грн».
- Рушій ставить наголоси неправильно або не ставить зовсім.
- У тексті є власні назви (топоніми, прізвища, бренди), яких немає у словнику.
- Треба віддати один і той самий текст різним рушіям — у кожного свій формат наголосу.

## Швидкий старт

```bash
# один раз: словник наголосів (~70 МБ, 2,8 млн словоформ)
node scripts/fetch-dict.mjs

# підготовка під конкретний рушій
node scripts/cli.mjs --engine tts-uk < script.txt > prepared.txt
```

Або з коду:

```ts
import { StressDictionary, Lexicon, prepare } from 'ua-tts-text';

const dictionary = StressDictionary.load('./data/dict.bin');
const lexicon = Lexicon.loadTsv('./lexicon/names.tsv');
const result = prepare(text, { dictionary, lexicon, engine: 'tts-uk' });
```

## Порядок роботи

1. **Визнач рушій.** Від нього залежить формат наголосу (таблиця нижче). Якщо рушій невідомий — використай `plain`: текст нормалізується без позначок.
2. **Проганяй текст через CLI** і читай звіт у stderr: `наголошено`, `омоніми`, `немає у словнику`, `проблеми`.
3. **Розв'яжи омоніми.** Для кожного слова зі звіту подивись на контекст і обери варіант `0` або `1`:
   ```json
   { "замок": 0, "горі": 1 }
   ```
   Передай рішення як `stress.decisions` (у CLI — `--decisions decisions.json`).
4. **Перевір `проблеми`.** Якщо в тексті лишились цифри, дужки або латинка — виправ текст сценарію, а не добивай позначки вручну.
5. **Повтори прогін**, поки `омоніми` не стане порожнім. Отриманий `text` віддавай у TTS.

## Профілі рушіїв

| Рушій | Що ставимо | Примітка |
|---|---|---|
| `tts-uk`, `holos-voice` | `+` перед голосною | модель навчена саме на такому записі |
| `silero`, `rhvoice` | `+` перед голосною | за документацією рушіїв |
| `styletts2` | `+` після складу | за документацією |
| `piper-medium` | акут U+0301 | символьна модель `uk_UA-ukrainian_tts-medium` |
| `piper-high` | нічого | espeak-ng ставить наголос сам; `+` він читає як «плюс» |
| `elevenlabs-v4` | IPA (у роботі) | для неанглійської IPA лише на `eleven_v4`/`v4_turbo` |
| `edge-tts`, `azure` | нічого | наголоси не приймають |

`piper-high` — не помилка у тексті: ці голоси фонемізуються espeak-ng, який ігнорує будь-які текстові позначки наголосу. Виправляти треба вибір рушія, а не текст.

## Правила

- **Не вигадуй наголос.** Якщо слова немає ні в словнику, ні в лексиконі — або додай його в `lexicon/names.tsv` з наголошеною формою, або лиши як є й познач для людини.
- **Не чіпай латинку.** `YouTube`, `Starlink` — це рішення для людини: транслітерація чи залишити.
- **Один текст — один рушій.** Не змішуй у одному файлі `+` і акути.
- **Словник не є істиною.** У lang-uk трапляються помилкові варіанти (наприклад, «Киї́в»); лексикон має пріоритет.

## Формат лексикону

`lexicon/names.tsv`, колонки через табуляцію:

```
Київ	Ки́їв	власна назва	manual: словник має помилковий варіант
```

Перша колонка — як слово пишеться, друга — з акутом після наголошеної голосної (два акути — для складних назв на кшталт `Кам’яне́ць-Поді́льський`).

## Обмеження

- Числа читаються в називному відмінку.
- Діапазони «5–7» не переписуються у «від п'яти до семи».
- Латинські назви не транслітеруються.
- Абревіатури — невелика таблиця; решта лишається як є.
