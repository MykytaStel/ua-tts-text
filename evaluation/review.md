# Що перевірити у золотому наборі

`evaluation/gold.tsv` — 20 речень. Колонки: `id`, текст із наголосами, теги.
Акут (´) стоїть після наголошеної голосної. Слова без акута вважаються такими,
що не потребують позначки.

Поточний стан: **точність 97,8%, повнота 82,9%** (F1 89,7%). Низька повнота —
це переважно омоніми, які рушій свідомо не вгадує.

## Спірні місця — потрібне твоє рішення

| Слово | У золоті | Словник | Питання |
|---|---|---|---|
| `пере́пад` / `перепа́д` | перепа́д | пере́пад | як кажуть у тебе? |
| `зупи́нимося` / `зупинимо́ся` | зупи́нимося | зупинимо́ся | |
| `по́вість` / `пові́сть` | по́вість | омонім | |
| `яку́` / `я́ку` | яку́ | омонім | |
| `до́сі` / `досі́` | до́сі | омонім | |
| `дя́кую` / `дяку́ю` | дякую | омонім | |
| `рі́зні` / `різні́` | рі́зні | омонім | |
| `мі́ста` / `міста́` | міста (міста-місця) | омонім | |

## Як виправити

Відкрий `evaluation/gold.tsv`, постав акут на потрібну голосну (або прибери).
Потім:

```bash
node scripts/eval.mjs
```

Якщо слово справді має два рівноправні наголоси — прибери акут, і воно піде
в «не потребує позначки».

## Чого не вистачає

- речень з іменами твоїх персонажів і топонімів (найбільша дірка);
- складних чисел у відмінках («про двох тисяч»);
- питальних і окличних речень для перевірки плану мовлення.
