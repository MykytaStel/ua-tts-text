# Золотий набір: що вирішено

`evaluation/gold.tsv` — 20 речень із нормативними наголосами. Колонки: `id`,
текст із акутами, теги. Акут стоїть після наголошеної голосної.

## Рішення щодо спірних слів (перевірено носієм мови)

| Слово | Норма | Чому |
|---|---|---|
| пере́пад | пере́пад | наголос на другому «е»; «перепа́д» — не норма |
| зупинимо́ся | зупинимо́ся | повна форма; «зупини́мся» — інша форма, не варіант |
| по́вість | по́вість | «пові́сть» — рідкісне дієслово «повісти» |
| яку́ | яку́ | «я́ку» — давальний відмінок «як» (тварина) |
| до́сі | до́сі | «досі́» — рідкісний іменник, не прислівник |
| дя́кую | дя́кую | «дяку́ю» — рідкісне значення |
| рі́зні | рі́зні | «різні́» — родовий відмінок «різня» |
| мі́ста / міста́ | залежить від граматики | родовий однини vs називний множини |

П'ять із них із однозначним рішенням перенесено в `lexicon/common.tsv`, щоб
рушій брав загальне значення за замовчуванням.

## Поточний стан

```
точність 100,0%   повнота 90,5%   F1 95,0%
```

Решта помилок — справжні омоніми, які не можна вирішити без речення:
за́мок / замо́к, го́рі / горі́, доро́га / дорога́, ве́де / веде́,
се́ла / села́, со́рок / соро́к, п'я́ти / п'яти́, мі́ста / міста́.
Їх закриває LLM-резолвер (`prepareMany` з `ask`) або людина.

## Як додати речення

1. Додай рядок у `evaluation/gold.tsv`: `g21`, текст із акутами, теги.
2. `node scripts/eval.mjs` — побачиш, чи рушій згоден.
3. Якщо слово спірне — додай його в таблицю вище з поясненням.
