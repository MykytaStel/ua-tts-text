# ua-tts-text

Готує український текст до озвучки: числа й дати словами, скорочення, наголоси
у форматі конкретного рушія TTS.

Проблема, яку розв'язує: більшість рушіїв читають «1675» якось собі, «ст.» — як
«ст», а наголоси або не розуміють зовсім, або розуміють кожен по-своєму.

## Стан

| Блок | Стан |
|---|---|
| `normalize()` — числа, роки, дати, відсотки, одиниці, скорочення, пунктуація | ✅ працює, 40 тестів |
| `stress()` — наголоси словником + список омонімів | ⏳ у роботі |
| `render()` — профілі рушіїв (acute / `+` / IPA / alias) | ⏳ у роботі |
| `review()` + `qa()` — що перевірити людині й що не пропустити в синтез | ⏳ у роботі |
| Лексикон власних назв | ⏳ у роботі |

## Використання

```ts
import { normalize } from 'ua-tts-text';

normalize('у 1675 році на 5 км шляху — 22% вологи.');
// «у тисяча шістсот сімдесят п'ятому році на п'ять кілометрів шляху, двадцять два відсотки вологи.»
```

## Свідомі обмеження v0.1

- Числа читаються в називному відмінку. «Про 5 кг» → «про п'ять кілограмів», а не
  «про п'ять кілограмів» у знахідному — для TTS різниця нечутна, для граматики є.
- Діапазони «5–7» не переписуються у «від п'яти до семи».
- Абревіатури — лише невелика таблиця. Решта лишається як є, щоб не зіпсувати текст.
- Омоніми (за́мок / замо́к) поки не розв'язуються — це наступний крок.
